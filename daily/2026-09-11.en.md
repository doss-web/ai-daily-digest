**🔥 OpenAI launches the Agents API in public beta and opens full-duplex voice model GPT-Live-1 to developers**

The Agents API turns the harness that powers Codex (orchestration, long-running sessions, tool use) into a managed service; developers can run agent compute in an OpenAI-managed sandbox, their own infrastructure, or a partner sandbox. The latency bar for voice drops, but five cents a minute means it only pencils out for high-value scenarios (support, sales, triage).

**🔥 DeepSeek open-sources V4.1-Flash: 552B base plus Engram parameters, KV cache cut to 1/4**
- **What happened**: V4.1-Flash is a multimodal MoE model with 552B backbone parameters plus 196B Engram parameters (roughly 748B total), only 16B active per token, a 1M-token context window, FP4 KV cache, and cross-layer attention reuse. It narrowly beats Opus 5 and GPT-5.6 Sol on the DeepSWE coding benchmark and ships under the MIT license.
- **Why it matters**: The real bottleneck for long-horizon agents is repeated prefill and million-token contexts crushing HBM/SSD bandwidth with KV cache; V4.1-Flash is designed directly against that bottleneck. For teams running their own agents, this means far more concurrent sessions per GPU, and the MIT license permits commercial use and redistribution.
- **Connections**: Anthropic published a report the same day alleging distillation attacks by Chinese labs including DeepSeek; an argument over whether the model is 552B or 748B also flared up on r/LocalLLaMA that same day.
- Importance: ★★★★★

**🔥 Meta's Muse becomes the No. 2 app in the US, with payments running through Stripe Link**
- **What happened**: Muse is Meta's personal AI agent; it shops, writes emails, books travel, and negotiates prices through WhatsApp, with payments routed via Stripe's Link, plus a separate security agent called Sentinel that reviews every action before it reaches the internet.
