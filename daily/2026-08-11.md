**🔥 Claude 对黎曼猜想的推进：从 41.6% 到 67.2%**
- **发生了什么**：Anthropic 发布官方研究报告，探索 Claude 的数学能力边界，报告显示 Claude 将黎曼猜想相关证明的推进度从 41.6% 提升至 67.2%。这不是模型更新，而是对现有模型推理策略的改进成果，HN 上引发 123 分讨论。

- **关联动态**：DeepMind 的哈萨比斯同日预告"数学的 AI 第 37 手只剩时间问题"，两件事互相印证。
- 重要性：★★★★☆

**📄 DCAS：CLI 编码 agent 的微调数据被 OpenHands "垄断"了**
- **发生了什么**：论文发现，开源 CLI agent 的微调轨迹数据几乎全部在 OpenHands 环境下采集，导致在 OpenHands 下评测分数虚高，一旦换到其他脚手架，性能大幅下降。基础模型没有这种偏差，说明问题出在微调数据本身的场景单一。
- **为什么重要**：这是对当前开源编码 agent 评测体系的直接质疑——你在 benchmark 上看到的分数，可能只是"在 OpenHands 里跑得好"的分数。对于选型开源 agent 的团队，这是一个需要警惕的信号：在多脚手架环境下测试，不要只看单一 benchmark。
- 重要性：★★★★☆
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2608.06113)

**📄 SFT 冲突，RL 共存：多任务学习的理论与实证分析**
- **发生了什么**：论文发现 SFT 在多阶段多任务训练中会出现严重的任务冲突，而 RL 能让不同任务稳定共存。参数层面，RL 产生的更新是稀疏且近似正交的，这解释了为什么它能避免 SFT 的灾难性遗忘。
- **为什么重要**：直接指导训练策略选择——如果你在做多任务模型，SFT 阶段要谨慎设计的任务混合；而 RL 阶段天然更适合多任务扩展。对做模型训练的团队，这是可操作的架构级结论。
- 重要性：★★★★☆
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2608.03573)

**📄 The Optimizer Is the Agent：推理驱动的自动化搜索**
- **发生了什么**：ReASearch 框架不再使用显式的外层优化器（进化搜索、bandit 等），而是让单个 tool-using agent 自主决定评估什么、如何诊断失败、做哪些修改、何时停止。
- **为什么重要**：这是"优化器 agent 化"的一个清晰示范：把优化策略内化到 agent 里意味着提示词优化、程序优化、ML 工作流优化可以共用同一套推理框架。对做自动 Prompt 优化或者 AutoML 工具的人来说，这是一个值得关注的新范式。
- 重要性：★★★★☆
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2608.06714)

**📄 小模型也能当人类认知代理：规模在行为建模中几乎无关**
- **发生了什么**：研究团队训练了 14 个模型（135M 到 14B 参数、4 个架构家族）在 Psych-101 数据集上——该数据集包含 160 个实验中的 1070 万条人类选择记录。结果：分布内性能上规模几乎不起作用，所有模型落在一个窄带内。
- **为什么重要**：对做"人类行为模拟"或"认知代理"的团队，这是一个成本信号：14B 和 135M 差不多，说明任务本身的复杂度上限在数据而非模型。"小模型够用"的结论直接映射到推理成本上。
- 重要性：★★★★☆
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2608.05224)
