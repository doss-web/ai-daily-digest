## 📄 重要论文

**📄 SWE-Prime：更少的轨迹，更好的性能**
- **发生了什么**：arXiv 论文指出，coding agent 训练中"成功的轨迹不一定是高质量的监督信号"——成功轨迹中可能包含低效、冗余甚至危险的步骤，直接 SFT 会引入噪声。SWE-Prime 用更少的轨迹达到了更好的性能。
- **为什么重要**：对做 coding agent 数据管线的团队有直接指导意义：数据质量 > 数据量，需要区分"成功"与"高效且安全"。
- 重要性：★★★★★
- 来源：[arXiv](https://arxiv.org/abs/2608.27449v1)

**📄 PILOT in the Loop：长周期 Agent 的实时自我改进**
- **发生了什么**：提出"live self-improvement"——长周期 agent 在运行过程中就应利用新经验调整当前执行，而不是等执行结束后再离线分析。论文指出现有单 agent 架构无法完全支持这一目标，给出了多 agent 设计。
- **为什么重要**：长周期 agent 是当前 agent 工程的核心难题。运行中自我修正可能成为下一代 agent 框架的必备能力。
- 重要性：★★★★☆
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2608.26530)

**📄 TTPO：无需地面真值的测试时策略优化**
- **发生了什么**：现有 RL 后训练依赖地面真值标签，无法做 test-time training；用多数投票伪标签则会被错误投票污染。TTPO 观察到 rollout 中错误的不对称性，实现了无需地面真值的测试时优化。
- **为什么重要**：推理时 scaling 是最重要的效率杠杆之一。如果模型可以在推理过程中继续学习，长思考成本将大幅下降。
- 重要性：★★★★☆
- 来源：[arXiv](https://arxiv.org/abs/2608.27448)

**📄 CritICL：从小模型失败模式中实现推理时弱到强泛化**
- **发生了什么**：提出 CritICL 框架，利用同一模型家族内小模型的失败模式与大模型的结构相似性，在推理时指导大模型修正，无需重复生成或外部验证。
- **为什么重要**：为"弱模型辅助强模型推理"提供了新思路，成本远低于多数投票等重复采样方法。
- 重要性：★★★★☆
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2608.27455)
