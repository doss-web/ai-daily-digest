## 📄 重要论文

**📄 Know When to Stop：为减少过度思考的段级信用分配**
- **发生了什么**：推理模型的「过度思考」（overthinking）问题——生成冗长的含糊表述、放弃原思路、自相矛盾而消耗 token——长期以来被视为「长度问题」。这篇论文证明即使控制回答长度，错误轨迹中无产出的自我反思比例仍然显著更高。作者提出段级信用分配方法，识别自我反思「何时有用、何时有害」，从而在生成中及时终止无效思考。
- **为什么重要**：token 成本是推理模型落地的最大瓶颈之一。这项研究为「在正确的地方停止思考」提供了可操作的方法论，直接关系到推理 API 的成本优化。
- 重要性：★★★★☆
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2607.00482)

**📄 Test-Time Scaling 统一框架：推理范式、评估与可复现性**
- **发生了什么**：随着推理时计算扩展成为提升 LLM 推理能力的主要手段，「test-time scaling」一词已涵盖多种截然不同的算法：沿单轨迹扩展思考、采样多个候选并通过投票/验证聚合、以及搜索部分状态。论文指出这些算法在统计结构、计算核算和失败模式上存在根本差异，不能混为一谈，并提出了统一的评估框架。
- **为什么重要**：当前大多数 test-time scaling 的对比研究混淆了不同推理范式，导致结论不可迁移。这篇综述+统一框架是推理成本优化和模型选型的必读参考。
- 重要性：★★★★☆
- 来源：[arXiv](https://arxiv.org/abs/2608.04001v1)

**📄 LLaDA MoE v2：扩散语言模型的 MoE 扩展规律**
- **发生了什么**：扩散语言模型（dLLM）被视为自回归模型的替代范式，但其 MoE 扩展行为此前未被系统研究。这篇论文系统刻画了 MoE dLLM 在优化超参数、计算分配和架构上的扩展规律，发现与自回归模型存在定量差异——最优名义 batch size 增长更快、最优学习率衰减趋势不同等。
- **为什么重要**：如果扩散 LM 要走大规模路线，这些扩展规律直接决定训练成本和架构选择。对关注非自回归范式的团队有参考价值。
- 重要性：★★★★☆
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2608.03457)

**📄 CALVER：当投票失效时，用符号验证保证因果推理**
- **发生了什么**：self-consistency 假设投票最多的答案最可靠，但在因果推理中该假设经常失效：采样轨迹常重复同样的混杂偏误，且有效答案分散在多个候选上，导致错误答案胜出。论文提出 CALVER，一个无需训练的符号验证器，基于 Pearl 因果准则（d-separation、后门调整等）对推理轨迹评分。
- **为什么重要**：投票/采样聚合是当前最流行的推理增强手段之一，但论文揭示了其在因果场景中的系统性缺陷。CALVER 提供了一种无需训练即可增强推理可靠性的方法，对 Agent 决策场景有直接应用价值。
- 重要性：★★★★☆
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2608.03506)

**📄 ARCHead：权重量化时代的 LM-Head 压缩**
- **发生了什么**：权重量化虽能大幅压缩 LLM 的 transformer 块，但实际部署中 LM-head 往往保留在 BF16/FP16，成为内存瓶颈。ARCHead 提出组合式压缩方案：量化低秩核心 + 分组 INT4 残差 + 基于激活度量的低秩校正，无需存储密集权重即可恢复词表 logit 分布。
- **为什么重要**：对部署超大模型的团队来说，LM-head 压缩是尚未被充分开发的优化空间。ARCHead 可能在 KV cache 量化之外开辟新的内存节省路径。
- 重要性：★★★☆☆
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2608.02703)
