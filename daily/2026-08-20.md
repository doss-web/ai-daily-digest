## 📄 重要论文

**📄 LEGO-RL：面向 Coding Agent 的 Harness 原生强化学习**
- **发生了什么**：现有 RL 训练 coding agent 时，agent harness（工具集成、仓库上下文、执行反馈）的本地执行环境与 policy-gradient 训练天然不兼容——环境崩溃和 reward hacking 会污染结果信号。LEGO-RL 提出了一套框架，弥合 harness 原生执行与 RL 训练之间的鸿沟。
- **为什么重要**：这是"harnessed agentic RL"范式（Agent Lightning 开创、verl/Uni-Agent 等跟进）的又一重要推进。对做 agent 训练的团队来说，LEGO-RL 直接解决了"训练环境和部署环境不一致"这个老大难问题。
- 重要性：★★★★★
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2608.17393)

**📄 HarnessRisk：面向 Agent Harness 安全的生命周期基准**
- **发生了什么**：LLM 越来越多地通过 agent harness 部署（管理工具、扩展、持久状态、权限和外部操作），但现有安全基准只针对单一攻击机制。HarnessRisk 将 harness 安全组织为六个运维阶段，系统评估安全失效如何在不同的 harness 职责之间产生和传播。
- **为什么重要**：随着 agent 从 demo 走向生产，harness 层（而非模型本身）正成为安全主战场。这个基准为 agent 基础设施的安全性提供了可量化的评估框架，任何构建 agent harness 的开发团队都值得关注。
- **关联动态**：与当天 Codex 删文件事故以及 OpenAI 因网络安全风险暂停训练直接呼应——agent 安全问题已经从研究议题变成现实事故。
- 重要性：★★★★★
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2608.17597)

**📄 Abra：扩散图像训练的 Scaling Law**
- **发生了什么**：文本到图像扩散模型此前缺乏类似 LLM 的 compute-optimal scaling law 研究。Abra 用一组受控的 flow-matching transformer 在 10^19 到 10^22 FLOPs 三个数量级的计算预算下训练，证明扩散模型的 scaling 行为和语言模型一样可预测。
- **为什么重要**：这意味着图像生成模型的规模扩展可以像 LLM 一样"按计算预算精确规划"，而不是靠经验试错。对训练或微调扩散模型的团队，这是一份可以直接指导资源分配的参考。
- 重要性：★★★★☆
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2608.17286)

**📄 自改进 Agent 的脆弱性：方差、任务顺序与欠规定化**
- **发生了什么**：这篇论文对两类基于记忆的自改进 agent 方法进行了全面复评，扩展了两个维度：多次运行以量化方差，以及随机打乱任务顺序。结果显示这类方法的可靠性存在此前被忽视的严重问题——性能对任务顺序高度敏感，而单一运行结果容易给出误导性结论。
- **为什么重要**："让 agent 从经验中不断自我改进"是当下最热门的方向之一，但很多结论可能是实验设置带来的假象。任何一个正在做 memory-based agent 的团队都应该读一下这篇论文，它能帮你避免在不可靠的基础上继续堆叠。
- 重要性：★★★★★
- 来源：[arXiv](https://arxiv.org/abs/2608.18066v1)

**📄 StartupBench：基于市场验证的端到端 Agent 基准**
- **发生了什么**：现有 agent 基准大多由研究者自行挑选任务，和真实用户的实际需求存在脱节。StartupBench 将任务定义建立在"市场验证过的 AI 创业公司产品"之上——从真实被付费使用的产品中反向提取有代表性的工作任务。

## 🐦 AI 圈热议

**💬 r/LocalLLaMA 热议：Qwen3.8 的"过度思考"不是拟人化的"推理"**
- **发生了什么**：LocalLLaMA 社区针对 Qwen3.8-27B 的"overthinking"问题展开了一场方法论争论。有帖子标题直言"Stop Anthropomorphizing Intermediate Tokens"，核心观点是：中间 token（被称作"思考"或"推理"）实际上和人类推理没有任何关系——"人类是逐步推理得出结论，而 LLM 是用中间 trace 来增强 prompt"。帖子引用的研究指出，"中间推理过程并不忠于模型最终答案"（与 2025 年 HN 上热门的 arXiv 论文 Chain-of-Thought Reasoning in the Wild Is Not Always Faithful 遥相呼应）。
- **为什么重要**：这不仅是术语之争。如果中间 token 不是"推理"，那么当前围绕 CoT 的 evals、安全对齐和可解释性工作都需要重新审视基础假设。对正在调试 agent 推理链的开发者来说，理解这一点能避免在错误的方向上浪费时间。
- 热度：🔥🔥🔥🔥
- 来源：[r/LocalLLaMA](https://www.reddit.com/r/LocalLLaMA/comments/1vsjcf7/stop_anthropomorphisizing_intermediate_tokens/)
