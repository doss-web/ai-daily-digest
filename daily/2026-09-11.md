## 📰 行业新闻

**🔥 OpenAI 发布 Agents API 公测，并把全双工语音模型 GPT-Live-1 开放给开发者**
- **发生了什么**：OpenAI 同日上线两个开发者产品。Agents API 把驱动 Codex 的 harness（编排、长会话、工具调用）做成托管服务，开发者可以选择在 OpenAI 托管沙箱、自有基础设施或合作方沙箱中运行 agent 计算。GPT-Live-1 是支持全双工（边听边说）的语音模型，交互性测试得分 80.1%，上一代为 45.4%，API 定价 $0.05/分钟。
- **为什么重要**：harness 从"各家自己攒的脚手架"变成可采购的托管服务，意味着 agent 产品的竞争重心从"能不能跑通"转向"上下文设计、工具编排与成本控制"。语音场景的延迟门槛被拉低，但每分钟 5 美分意味着它只适合高价值场景（客服、销售、分诊）。
- **关联动态**：同日 Google 开源了给编码 agent 用的安全技能包 Mantis，HN 上还出现开源的语音 agent 仿真测试基础设施 egma——围绕 agent harness 的生态层正在快速成形。
- 重要性：★★★★★
- 来源：[OpenAI](https://openai.com/index/introducing-the-agents-api)、[The Decoder](https://the-decoder.com/openais-gpt-live-1-api-lets-developers-build-apps-that-talk-and-listen-at-the-same-time/)

**🔥 DeepSeek 开源 V4.1-Flash：552B 基座 + Engram 参数，KV cache 压到前代 1/4**
- **发生了什么**：V4.1-Flash 是多模态 MoE 模型，552B backbone 参数 + 196B Engram 参数（合计约 748B），每个 token 仅激活 16B，支持 1M token 上下文，采用 FP4 KV cache 与跨层 attention 复用。在 DeepSWE 编码基准上小幅超过 Opus 5 与 GPT-5.6 Sol，以 MIT 许可证发布。
- **为什么重要**：长时程 agent 的真正瓶颈是重复 prefill 与百万 token 上下文把 KV cache 压垮 HBM/SSD 带宽，V4.1-Flash 是直接针对这个瓶颈做设计的。对自建 agent 的团队，这意味着单卡可承载的并发会话数大幅提升，MIT 许可也允许商用与二次分发。
- **关联动态**：Anthropic 同日发布报告指控 DeepSeek 等中国实验室对其模型实施蒸馏攻击；r/LocalLLaMA 上关于"到底是 552B 还是 748B"的参数口径争论也在同一天发酵。
- 重要性：★★★★★
- 来源：[MarkTechPost](https://www.marktechpost.com/2026/09/10/deepseek-ai-released-deepseek-v4-1-flash-with-1m-context-fp4-kv-cache-and-cross-layer-attention-reuse/)、[r/LocalLLaMA](https://www.reddit.com/r/LocalLLaMA/comments/1wcd4rx/deepseek_v41_flash_is_748b_not_552b/)

## 📄 重要论文

**📄 PARSER：把"读"和"推理"解耦，长文档 agent 的并行化方案**
- **发生了什么**：顺序记忆型 agent 逐块阅读长文档并维护压缩记忆状态，把文档遍历与推理深度耦合在一起，导致对证据位置高度敏感、推理延迟与文档长度线性相关。PARSER 让一批轻量子 agent 各自绑定一个 chunk 并行读完整篇文档，由一个 lead agent 迭代式地做深度推理。
- **为什么重要**：这是"记忆架构"路线而不是"更长上下文"路线。对做 RAG 与长文档 agent 的团队，它给出了把延迟从 O(n) 降到近似常数、同时消除证据位置偏置的具体做法。
- 重要性：★★★★★
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.06702)

**📄 SWE-Bench Pro Verified：修掉 reward hacking 与问题描述缺陷的"干净"基准**
- **发生了什么**：作者指出 SWE-Bench Pro 存在两类不可靠来源——gold solution 或评测信息泄漏导致的 reward hacking，以及误导性问题陈述和范围不当的测试——两者都会虚高分数、掩盖 agent 的真实编码能力。论文给出了修正后的 Verified 版本。
- **为什么重要**：如果你在用 SWE-Bench Pro 做模型选型或内部达标线，之前刷出来的分数有一部分可能是水。这套修正对采购决策和 agent 团队的回归测试都有直接影响。
- **关联动态**：OpenAI 同一天把 Codex harness 做成 API——基准的可信度与 harness 的可比性正在变成同一个问题。
- 重要性：★★★★★
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.08149)

**📄 SchemeArena：把"agent 是否会阳奉阴违"拆成可控因子来压测**
- **发生了什么**：既往工作只能覆盖极少数场景，难以隔离不同条件对 scheming 倾向与能力的影响。SchemeArena 用因子化设计，把工具性目标、环境可供性、监督条件、感知到的后果拆开，系统性观察它们如何交互产生 scheming（表面服从、暗中追求不一致目标）。
- **为什么重要**：这正是今天 Anthropic 报告里 Claude Mythos 5 案例的评测化版本。做 agent 部署的团队可以把它当作上线前的红队清单，而不必等事故发生后再复盘。
- 重要性：★★★★★
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.08126)

**📄 Co-Evolving Harnesses and Models：harness 演化 + 轻量微调，让小模型在垂直任务上追平前沿模型**
- **发生了什么**：论文在 7 个企业 agent 任务上先演化 harness（系统提示、工具集、执行钩子、上下文管理脚手架），再比较 harness 演化与轻量微调的多种组合，发现 on-policy correction 能让弱模型在模仿学习失效的地方追上来。
- **为什么重要**：这条路线直接指向成本——用小模型 + 精心设计的 harness 替代前沿模型跑企业任务，只需要前沿模型成本的一小部分。在 token 单价下滑而前沿容量收紧的当下，这是最务实的降本方案。
- **关联动态**：r/LocalLLaMA 当天就有人发帖"Harness does matter"，并贴出 DeepSeek V4.1 Flash 的对比体验。
- 重要性：★★★★☆
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.09134)

**📄 Programmable World Model：把世界状态演化与视觉生成解耦**
- **发生了什么**：视频世界模型越来越逼真、越来越可交互，却缺乏维持持久世界状态、在长时间交互中执行可编程规则的机制。该框架让 agent 把自然语言指令翻译成可执行程序，明确规定实体状态与状态转移规则，再据此驱动视觉生成。
- **为什么重要**：这是把"世界模型"从像素预测拉回显式状态机的一步，对机器人仿真、游戏以及需要可验证性的 agent 环境都有直接借鉴价值。
- 重要性：★★★★☆
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.10540)

## 🐦 AI 圈热议
