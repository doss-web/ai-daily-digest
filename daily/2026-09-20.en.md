**🔥 Google DeepMind releases Dream-RSI: agents improve by "dreaming" through past searches**
- **What happened**: Dream-RSI lets AI agents replay past search trajectories in a "dream" state to test new strategies without re-running costly computation. In tests it matched or beat existing results while cutting iterations by up to 2.43x. Crucially, only the search strategy adapts; the underlying model is untouched.
- **Why it matters**: This is a textbook case of spending test-time compute on the strategy layer rather than the model layer, meaning you can improve agent performance without retraining. Any team doing RAG, hyperparameter search or multi-turn tool use should port this idea into their own search loop.
- **Connections**: It mirrors the Self-Evolving Search Index paper on HuggingFace today — the index or policy itself becomes the thing that evolves.
- Importance: ★★★★★
- Source: [The Decoder](https://the-decoder.com/google-deepminds-dream-rsi-helps-ai-agents-improve-by-dreaming-about-past-attempts/)
