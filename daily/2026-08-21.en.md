## 📄 Papers

**📄 Bounded Agents: Delegation Security for Multi-Agent AI Systems**
- **What happened**: The paper shows that current LLM agents have static permissions set at session start, with each request evaluated independently—allowing agents to combine individually permitted actions into prohibited outcomes, or delegate authority to sub-agents without limits. The authors propose a bounded delegation security framework.
- **Why it matters**: With static session permissions and per-request evaluation, delegation-chain vulnerabilities are a primary source of real-world multi-agent system incidents. Teams building multi-agent systems should pay close attention to dynamic permission constraints and permission-consumption mechanisms during delegation.
- Importance: ★★★★★
- Source: [Hugging Face](https://huggingface.co/papers/2608.15888)

**📄 SkillGate: Training In-Policy Skill Selection in Long-Horizon Agents**
- **What happened**: Agent frameworks increasingly package procedural knowledge as skills, with public libraries now holding thousands. But "which skill to read at which point" is a decision the policy makes mid-episode without any training signal. The authors show default outcome-rewarded RL cannot teach this, naming the structural cause "selector credit starvation," and propose SkillGate.
- **Why it matters**: As skill libraries explode, "choosing the right skill" matters more than "skill quality." This is a warning for all developers using skill libraries—current approaches may be training agents that read the wrong instruction manuals.
- Importance: ★★★★★
- Source: [Hugging Face](https://huggingface.co/papers/2608.18852)

**📄 SPADE: Self-Play in Adaptive Synthetic Executable Environments**
- **What happened**: SPADE has the same LLM play two roles—an "Environment Designer" that writes complete long-horizon training environments, and a "Learner" that executes tasks and improves. Through adversarial co-evolution, the training goal distribution adapts as the learner scales, without relying on static datasets or frozen verifiers.
- **Why it matters**: This is a new paradigm for solving the training-environment bottleneck in RL. For domains where real-world environment feedback is unavailable, SPADE offers a sustainable self-improvement path. Researchers and teams doing agent training should read this in depth.
- Importance: ★★★★★
- Source: [Hugging Face](https://huggingface.co/papers/2608.19197)

**📄 LEGO-RL: Harness-Native Reinforcement Learning for Coding Agents**
- **What happened**: The paper identifies a fundamental mismatch between agent harness execution environments and policy-gradient training: environment crashes and reward hacking corrupt outcome signals, while train-inference discrepancies decouple rollout behavior from policy updates. LEGO-RL proposes a bridging framework for native-harness RL training.
- **Why it matters**: RL training for coding agents is one of the hottest directions, but harness-level engineering problems are severely underestimated. LEGO-RL is among the first systematic works to address this at the framework level, with direct reference value for agent-training teams.
- Importance: ★★★★☆
- Source: [Hugging Face](https://huggingface.co/papers/2608.17393)

**📄 PTXBench: Benchmarking LLMs for GPU Kernel Optimization with Architecture-Specific PTX**
- **What happened**: PTXBench measures LLMs' ability to use architecture-specific PTX (rather than generic CUDA) for GPU kernel optimization, covering GEMM and attention workloads on H100 and B200. Results show success rates drop substantially on complex attention backward workloads—LLM PTX capability is highly uneven.
- **Why it matters**: This is a serious test for the "LLMs write kernels that beat compilers" narrative. As systems like ByteDance's CUDA Agent emerge, PTXBench provides a much stricter evaluation standard—using instruction-level PTX to optimize kernels may become the next main battleground for inference performance.
- **Connections**: ByteDance Seed's CUDA Agent claims 74% pass rate on KernelBench—PTXBench is its next difficulty tier.
- Importance: ★★★★☆
- Source: [Hugging Face](https://huggingface.co/papers/2608.17379)
