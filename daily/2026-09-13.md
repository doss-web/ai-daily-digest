## 📄 重要论文

**📄 Negative Self-Distillation：用"避开缺陷"代替"模仿正确答案"**
- **发生了什么**：On-Policy Self-Distillation（OPSD）已成为 LLM 自我改进的主流范式，模型以自身为老师、借助 ground-truth 等特权信息生成推理轨迹。但论文指出，OPSD 在复杂推理任务上会严重损害性能：强迫学生模仿一个依赖特权信息、被人为塑造得过度自信的推理轨迹，会抑制模型自身的表达与探索。作者提出 Negative Self-Distillation，把学习信号从"模仿正确答案"转向"识别并避开有缺陷的推理路径"。
- **为什么重要**：任何在做 RL 后训练或 self-improvement 流水线的团队都应该读这篇——它给出了一个反直觉但重要的结论：让模型"看着答案学"可能是在教它演戏，而不是推理。对照实验的思路可以直接迁移到自己的训练配方里。
- 重要性：★★★★★
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.11699)

**📄 一份开源的 IMO 金牌配方：用 Nemotron 训练奥数证明**
- **发生了什么**：论文系统研究了后训练与测试时推理设计如何影响自然语言奥数证明生成。作者从 Nemotron 3 Ultra 出发，用监督微调与强化学习训练出两个专家 checkpoint，并系统评估了 checkpoint 选择、验证与精修的作用。最终给出一条完全不依赖形式化证明器、外部工具或联网搜索的开放模型测试时计算流水线。
- **为什么重要**：价值在于"开放配方"这四个字——它把 IMO 级别数学推理从少数实验室的私有工程，变成一份可复现的流程（checkpoint 怎么选、验证怎么做、精修什么时候停）。做长链条推理产品的团队，可以直接借鉴其中的验证与精修环节。
- 重要性：★★★★★
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.10712)

**📄 NCP-ArchPreview：用"下一概念预测"把语言模型推向隐空间**
- **发生了什么**：论文提出 NCP-ArchPreview，在标准 next-token prediction 之外，引入 Next Concept Prediction——预测跨越多个 token 的离散"概念"。模型通过乘积量化构建隐空间概念词表，在保留 token 级自回归生成能力的同时，增加一个显式的、更具挑战性的概念级目标。
- **为什么重要**：这是对"自回归下一个 token"这一统治性范式少见的正面挑战，且没有抛弃 token 级生成（意味着可与现有推理栈兼容）。如果你的团队在关注超越 NTP 的预训练目标，这是当前值得跟踪的一条路线。
- 重要性：★★★★★
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.10715)

**📄 T1：面向长周期任务的终端 Agent 强化学习**
- **发生了什么**：T1 是一个 122B 总参数的 MoE 模型，用强化学习训练，在云沙箱中操作真实 shell，单任务可执行 300+ 轮工具调用，奖励信号来自每个任务自带的 verifier。论文给出了完整配方：用激进的热启动稳定 actor-critic 训练，配合稠密过程奖励。
- **为什么重要**：长周期终端任务是当前 agent 能力最薄弱、商业价值最明确的一环。这份工作最有价值的部分不是模型本身，而是"用任务自带 verifier 做奖励"的工程范式——它给出了一条不依赖人工标注的可扩展路径。
- 重要性：★★★★★
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.11042)

**📄 把图像 Tokenizer 当作统一多模态模型中的"视觉语言"来研究**
- **发生了什么**：图像 tokenizer 定义着统一多模态模型的"视觉语言"，但现有研究多依赖孤立指标或只做生成/理解单向评测，无法反映视觉 token 与文本联合建模时的真实行为。作者构建了一个受控的纯自回归测试台，在多模态持续预训练过程中跟踪文本、图像、T2I、I2T 四类任务的验证损失变化。
- **为什么重要**：统一多模态模型的很多"玄学"问题根源在 tokenizer，而这篇给出了一个可复用的诊断方法——用持续预训练过程中的分任务损失曲线来观察视觉 token 的联合行为，而不是只看最终 benchmark 分数。
- 重要性：★★★★★
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.09143)
