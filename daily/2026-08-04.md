## 📄 重要论文

**📄 Constitutional Midtraining：把对齐"焊死"进参数，而非只停留在后训练**
- **发生了什么**：120B 规模实验，将基于 Anthropic 宪法的价值观内容插入中训练阶段（midtraining），与纯回放对照组对比。采用 2×2 因子设计（课程顺序 × 深思推理），检验对齐能否在后续微调后仍然持久。结果是：内容存在性显著驱动对齐收益。
- **为什么重要**：后训练对齐在微调下会退化是已知痛点。如果对齐可以通过中训练"内化"进参数，对齐技术栈的时序设计将被改写——安全不再依赖最后一道容易被擦除的防线。
- 重要性：★★★★★
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2607.26654)

**📄 From RLVR to RLSVR：任务变换让开放任务获得自验证奖励**
- **发生了什么**：RLVR（可验证奖励强化学习）只适用于数学和代码等确定性验证领域。本文提出通过任务变换（task transformation）将开放任务改写成可验证形式，诱导出 self-verifiable rewards，让 LLM 在写作、创意、研究等开放领域也能自我改进。
- **为什么重要**：如果自验证奖励成立，开放领域的 RL 训练将不再依赖奖励模型和 LLM judge，评估偏差和推理成本同时下降。这是 RLVR 范式能否扩展到全领域的关键一步。
- **关联动态**：与 SAF-OPD、β-OPSD 等论文同属 RLVR 与自蒸馏融合的活跃研究线——这个方向正在快速收敛。
- 重要性：★★★★★
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2607.23802)

**📄 Mental World Modeling：预测人的行为，必须建模心理状态**
- **发生了什么**：现有世界模型只回答物理问题——物体在哪、如何演化。但人类行为由隐藏的心理状态驱动（信念、欲望、意图、感受、社会许可）。作者提出心理世界建模（MWM），主张只追踪物理场景而不建模每个 agent 知道什么、相信什么的模型，会在"看起来正确的场景"上预测错误行为。
- **为什么重要**：从物理世界模型扩展到心理世界模型，是具身智能和 AI 仿真社会从"物理模拟器"走向"人类行为模拟器"的必经之路。对做 Agent 协作、社会模拟的研究者是直接的方法论更新。
- 重要性：★★★★☆
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2607.27201)

**📄 RL²-VLA：VLA 模型的测试时扩展**
- **发生了什么**：VLA（视觉-语言-动作）模型在域外和困难任务上性能退化。本文提出自适应 RL 潜变量组合控制 + 测试时扩展，让动作采样突破"相似行为聚集"的相关失败模式，且不依赖大量数据收集和重训练。
- **为什么重要**：测试时扩展正在从 LLM 走向具身智能。机器人领域将迎来与 LLM 相同的范式——推理算力越多，任务成功率越高。对做机器人策略的团队，这是必须跟踪的方向。
- 重要性：★★★★☆
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2607.26991)

**📄 Safeguards Based on Copyable Context Cannot Provide Reliable Safety for LLMs**
- **发生了什么**：LLM 安全护栏在回答之前就决定是否回答，但双用任务（dual-use）中同一答案既能帮助合规专业人员也能帮助攻击者。本文严格证明了：当下游使用证据是可复制（copyable）的，攻击者协助程度存在无法规避的最坏情况下限。
- **为什么重要**：这是对基于上下文内容的安全机制的数学级否定。安全设计必须转向不可复制的证据——用户身份验证、行为模式、环境可信度——而不是依赖提示词和上下文过滤。
- 重要性：★★★★★
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2607.27951)

**🛠 NVIDIA 开源 Molt：PyTorch 原生 agentic RL 框架**
- **发生了什么**：约 8,600 行 RL 代码，将 Ray、vLLM、NeMo AutoModel 组合进单一异步循环。agent 保持普通 Python，轨迹保持 token-exact，吞吐量与 Megatron 技术栈统计相当。
- **为什么重要**：Agentic RL 研究的最大成本是工程复杂度——每改一个算法都要动 trainer、分布式后端和 rollout 胶水。Molt 把这条链路压缩到一个异步循环里，研究迭代速度可以提升一个数量级。
- 重要性：★★★★★
- 来源：[MarkTechPost](https://www.marktechpost.com/2026/08/01/nvidia-ai-releases-molt-a-pytorch-native-agentic-reinforcement-learning-framework/)

**🛠 TencentDB Agent Memory：腾讯开源的团队级 Agent 记忆中心**
