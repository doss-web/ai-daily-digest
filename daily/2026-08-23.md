**📄 NVIDIA：跨模型 KV cache 转移，用线性数学替代昂贵的模型间交接**
- **发生了什么**：NVIDIA 研究人员提出一种跨模型 KV cache 转移技术，将源模型预填充好的 KV cache 直接映射到目标模型中，避免目标模型将整段对话从零开始重新计算。在 agent 系统将任务从小模型切换到大模型（或反向）时，这一技术可绕开当前必须支付的"重算税"。
- **为什么重要**：这是多模型 agent 工作流的长期痛点——任务越复杂、对话越长，模型交接的重复计算就越贵。该技术若落地，小模型规划 + 大模型执行的经典架构将不再被重复计算拖累，长周期多 LLM 工作流的经济模型将被改写。
- 重要性：★★★★★
- 来源：[VentureBeat](https://venturebeat.com/technology/nvidia-finds-that-simple-linear-math-can-replace-costly-ai-model-handoffs)

**📄 The Embedder's Dilemma：LLM 做 Embedding 到底值不值？**
- **发生了什么**：论文对 10 个 LLM 与 26 个 embedding 模型（118M 到 14B 参数）在 37 个任务上做了受控、成本感知的对比。结果显示两类范式整体打成平手：最佳 LLM（Gemini 3.1 Pro，77.6 分）与最佳 embedding 模型（77.2 分）仅差 0.4 分，但强项分布完全不同。
