## 📄 重要论文

**📄 Transformers 想得太早停了，一个极小的 LoRA 就能修好**
- **发生了什么**：研究发现预训练 transformer 只用了很少的深度去跟随上下文中的引用——13 个基座模型稳定跟随的引用链只有 1.4 到 3.6 行，额外的预训练循环几乎无帮助。作者在一个早期层挂上 rank-8 的 LoRA（其余权重全部冻结）：Qwen3-8B 在 24 行链上的精确准确率从 15.5% 提到 99%，训练更久的 LoRA 可达 50 行；Ouro-1.4B 在四次循环后到 60 行，八次后至少 160 行。LoRA 起到的是"接力"作用。
- **为什么重要**：如果瓶颈是"深度没用够"而非"参数不够多"，那么推理能力的边际收益可能来自在正确位置插入极小的适配器。rank-8 意味着训练预算和显存开销都可忽略——这是一条极低成本的推理增强路径。
- **关联动态**：同期 LoopCD 论文从解码侧利用同一类循环结构，两篇思路可组合。
- 重要性：★★★★★
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.36585)

**📄 Decoding Looped Transformers Better for (Almost) Free**
- **发生了什么**：循环 transformer 每个循环都会产生一个可解码下一个 token 的中间表示，但标准解码只用最后一次。LoopCD 提出免训练的对比解码框架，把较早循环（弱）与较晚循环（强）的输出配对，用来引导 token 选择，不需要辅助模型或额外训练。
- **为什么重要**：零训练、零成本的推理质量提升，已经在跑循环/迭代架构的团队可以直接接入。它也解释了为什么"多循环"往往不如预期——因为解码阶段把中间计算全丢了。
- 重要性：★★★★☆
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.02185)

**📄 MemFold：用 On-Policy 优化学习紧凑软记忆，服务长上下文个性化**
- **发生了什么**：长期服务同一用户的助手必须回答"哪些偏好仍成立、哪些已被修改、当前约束是什么"。但"保留信息"和"据其行动"目前被当作同一件事优化：存文本会让输入随历史线性增长，压成固定数量隐向量能约束接口大小，但通常只被训练来重建信息。MemFold 用 on-policy 优化学习紧凑软记忆。
- **为什么重要**：这是 agent 记忆系统里最实际的问题之一——记忆的评估目标应是下游行为正确，而非重建保真度。做长期记忆层的开发者可以据此重新设计压缩目标。
- 重要性：★★★★☆
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.36435)

**📄 Fewer Tokens, Better Action：GPT-6 Astra 机器人 agent 成功率 +14%、Token -65%**
- **发生了什么**：PyRUA-Lean 是一个交互式代码执行框架，让 VLM agent 把经典机器人原语与学习到的 VLA 策略组合成 Python 单元（内含条件检查和本地重试）来控制机器人，并做选择性观测。结果是成功率提高 14%，token 消耗减少 65%。
- **为什么重要**：这是"用代码执行替代逐步 token 推理"在机器人领域的实证。对任何做 agent 工具调用的开发者都可外推：把反馈循环下沉到代码里，比让模型多轮观测既便宜又准确。
- 重要性：★★★★★
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.01939)

**📄 谷歌 RRSI：阻止自我改进 agent"背题"**
- **发生了什么**：自我改进的 AI agent 倾向于记住测试任务，导致在新任务上的增益缩小甚至消失。Google 研究者提出 RRSI 抑制这一效应，在未见过的 benchmark 上最多提升 4.7 分，同时比未正则化版本少用约 30% token。
- **为什么重要**：自我改进循环中的 benchmark 污染正在快速变成主流失败模式。如果你在做 self-play、自我改写 prompt 或经验回放类系统，RRSI 提供了可复用的正则化思路，而且顺带省 token。
- **关联动态**：同期的 X-Tree 也在处理"经验如何复用而不退化"，只是从把可复用子过程 tokenize 切入。
- 重要性：★★★★☆
- 来源：[The Decoder](https://the-decoder.com/google-researchers-find-a-way-to-keep-self-improving-ai-agents-from-memorizing-their-tests/)
