## 📄 重要论文

**📄 Transformers Stop Thinking Too Early, and a Tiny LoRA Fixes It**
- **发生了什么**：研究发现预训练 Transformer 在上下文引用类任务上只用了很浅的深度：13 个基座模型可靠跟随的引用链长度只有 1.4–3.6 行，增加预训练的 loop 也几乎无益。作者在**某一早期层**训练一个 rank-8 的 LoRA 并冻结全部原始权重，Qwen3-8B 在 24 行引用链上的精确准确率从 15.5% 提升到 99%；训练更久的 LoRA 可外推到 50 行，Ouro-1.4B 在四次 loop 后达到 60 行、八次后至少 160 行。作者把这个 LoRA 描述为启动了某种"接力"机制。
- **为什么重要**：如果"深度利用不足"是普遍现象，那么当前的 scaling 讨论里有一部分能力其实是被免费搁置的，而激活它的代价只是一个 rank-8 适配器。对做长链推理、代码库级上下文、长文档引用的团队，这是一个极低成本的改良方向，值得先在自有基座上复现一次。
- 重要性：★★★★★
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.36585)

**📄 X-Tree: Tokenizing Reusable Experience for Efficient Agent Generalization**
- **发生了什么**：论文指出多步 agent 的训练数据是扁平的行动流，SFT 和 RLVR 对每个 token 一视同仁，因而忽略了跨任务复现的子过程（也就是人类做顶层规划时使用的可复用例程）。现有 agent 虽然会用到这种结构，但只是把它当作 LLM 在上下文里写的技能，从不进入权重，所以收益无法泛化到检索之外。X-Tree 转而从轨迹中恢复这种可复用的层级结构并 token 化。
- **为什么重要**：这是"agent 经验应该如何被存储"这一问题的权重层答案，与当前主流的上下文内技能库路线正面竞争。如果可复用子例程真能被写进参数，agent 的跨任务迁移效率会有量级变化，值得跟踪后续的对比实验。
- 重要性：★★★★★
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.32993)

**📄 MemFold: Learning Compact Soft Memory for Long-Context Personalization via On-Policy Optimization**
- **发生了什么**：论文处理长期服务同一用户的助手场景：需要记住哪些偏好仍然成立、哪些已被修改、当前适用哪些约束。作者指出"保留信息"和"根据信息行动"是两件事却被当成一件事优化——把历史保留为文本会让读者输入随历史增长，压缩成固定数量的隐向量虽然限定了接口，但通常只被训练来重建而非用于决策。MemFold 用 on-policy 优化学习紧凑的软记忆。
- **为什么重要**：个人化 agent 的记忆设计目前基本是工程拼凑（摘要 + 向量检索 + 定期压缩），这篇给出了一个把"记忆容量"与"决策效用"解耦的训练目标。做长期陪伴类、工作助手类 agent 的团队可以直接借鉴这个评价口径。
- 重要性：★★★★☆
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.36435)

**📄 Fewer Tokens, Better Action: GPT-6 Astra Robot Agents with 14% Higher Success Rate but 65% Fewer Tokens**
- **发生了什么**：论文提出 PyRUA-Lean，一个交互式代码执行框架，把反馈驱动的原子操作组合与选择性观察结合起来：agent 把经典机器人原语和学到的 VLA 策略组合成 Python 单元，在其中做条件判断和局部重试，从而避免重复调用模型和冗余观察。基于 GPT-6 Astra 的机器人 agent 成功率提升 14%，token 消耗减少 65%。
- **为什么重要**："让 agent 写代码来控制工具、在代码里做局部重试"这条路线在真实机器人任务上拿到了 65% 的 token 削减，说明它不只是省钱的技巧，而是能力提升的主因之一。任何用 VLM 驱动真实或模拟设备的团队都应该优先试这一模式。
- 重要性：★★★★★
- 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.01939)

**📄 Google 研究者的 RRSI：让自改进 agent 不再"背题"**
- **发生了什么**：自改进 agent 倾向于记住自己的测试任务，导致在新任务上的增益迅速衰减甚至消失。Google 研究者提出的 RRSI 方法抑制了这一效应，在未见过 benchmark 上最高提升 4.7 分，同时比未加正则化的版本少用约 30% 的 token。
- **为什么重要**：这是自进化 / self-improvement 方向最容易自欺的环节，RRSI 同时给出了精度和成本的改善，意味着它不太可能是用额外算力换来的假象。任何在做 agent 自我迭代 pipeline 的团队，都应该把"在未见任务上的增益"设为硬门槛，而不是只看训练分布内的曲线。
- **关联动态**：与同日 Keyword Harnesses Fail Open 指出的评测误判、以及 Generalization Is Stability 对泛化评价的重构，共同构成"评测可信度"这一正在成型的议题。
- 重要性：★★★★★
- 来源：[The Decoder](https://the-decoder.com/google-researchers-find-a-way-to-keep-self-improving-ai-agents-from-memorizing-their-tests/)
