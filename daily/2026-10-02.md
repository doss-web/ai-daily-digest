**🔥 Google 发布 Gemini 4 Argon：1M 输出 token，但访问受限、任务总成本存疑**
- **发生了什么**：Google DeepMind 发布 7 个多月来首个前沿模型 Gemini 4 Argon，单次输出上限从此前 6.4 万提升到 100 万 token。首席 AI 架构师 Koray Kavukcuoglu 称其在真实软件工程、法律金融等企业知识工作、以及网络安全防御上具备前沿性能，Google 已用它迁移了 80 万行内核代码。但访问被限制——先给"可信网络防御者"和部分测试者，API 与付费档后续开放。性能口径出现分歧：官方与部分报道（MarkTechPost、量子位、36Kr）称其多项基测压过 GPT-6 Astra 与 Claude Opus 5.5、成本仅 Astra 的约 60%；独立测评（The Decoder）则认为它与 Astra 打平、但仍追不上 Opus 5.5，且完成同一任务消耗的 token 是 Astra 的两倍以上。
- **为什么重要**：100 万输出 token 直接改变长产物任务的工程做法（大文件重构、代码库迁移、长篇结构化文档）。但"每 token 便宜 ≠ 每任务便宜"——按单价选型会算错账，必须按任务总 token 消耗折算。受限发布意味着短期内大多数团队拿不到，构建计划应预留回退到 Astra/Opus 的路径。

**📄 How Much Is an AI Token Worth? Scaling Laws for Wild AI-Generated Web Text**
- **发生了什么**：研究者在经过 FineWeb 质量过滤后，发现 2026 年 6 月的网页数据中有 27.5% 的 token 被 Pangram 判定为 AI 生成，到 8 月这一比例升至 31.1%。与合成数据或模型崩溃实验不同，这些"野外"AI 文本来自众多不同模型、是写给人类读者看的、并且在预训练语料中不带标注。论文随后量化了这类文本对语言模型预训练的影响。

**📄 Multimodal Flow: Unified Flow Modeling of Language and Vision in Embedding Spaces**
- **发生了什么**：论文提出一个完全连续的语言与视觉生成模型。现有统一多模态模型要么把语言和量化图像都当离散 token（引入视觉量化瓶颈），要么用离散语言预测搭配连续图像生成（需要模态相关的目标函数与采样流程）。Multimodal Flow 用单一连续的生成过程同时建模两者，规避了这两类取舍。
- **为什么重要**：如果这条路走通，统一多模态的训练与推理栈会显著简化——不必再维护两套目标和两套采样器。对正在自研多模态模型或做跨模态检索的团队，这是一个值得跟踪的架构方向。
- 重要性：★★★★☆
- 来源：[arXiv](https://arxiv.org/abs/2609.40362v1)

**📄 Physis-Lang: Self-Evolving Language as a Physical Representation for Video World Model**
- **发生了什么**：NVIDIA、MIT 与牛津的团队指出，视频世界模型能渲染出视觉上可信、却违反基本物理规律的片段（黄油像油漆一样抹开、球穿墙而过）。他们反驳了"自然语言不足以表达可靠生成所需的物理知识"这一常见假设，提出 Physis-Lang——把"物理语言"当作可共享、可优化的表示并让其自我演化，无需额外的视觉、隐空间、数值或规划信号，就把 Cosmos 3 在物理基准上推过了 Veo 3.1。

**📄 MILO: Automated Harness Discovery via Orchestrated Multi-Agent Evolution**

**📄 Prompted Identity Degrades Cooperation in Multi-Agent LLM Systems**
- **发生了什么**：论文发现，在多 agent 系统中，当 agent 知道彼此来自哪个模型家族时，群体合作会显著受损：agent 会分裂成同标签聚类，彼此更愿意与自己同源的 agent 互动——尽管任务中没有任何奖励或指令要求这种分裂。作者把这一现象定义为 factionalism，并指出标签本身就是成因。
