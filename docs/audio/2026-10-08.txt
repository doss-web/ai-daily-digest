AI 每日简报，周四，2026-10-08。以下是今天的重点。
行业新闻。
发生了什么。Anthropic 发布 Haiku 5.5，定价为 $0.10/$0.50 per M tokens（10 万 token 以内），超过 10 万 token 后价格上涨 5 倍至 $0.50/M 输出。前代 Haiku 4.5 发布于近一年前，定价 $1/$5——即使在当时也算贵，是 OpenAI 上月发布的 GPT-6 Luna 的整整 10 倍。基准上，Haiku 5.5 在 OSWorld 计算机操作测试中从 15.7% 跃升至 72.4%。The Decoder 提醒：新 tokenizer 每个任务会消耗更多 token，会吃掉一部分降价收益。
为什么重要。如果你在做计算机操作或浏览器自动化 agent，OSWorld 近 4.6 倍的提升意味着 Haiku 级别的模型第一次具备可用的 GUI 操作能力，而且落在最低成本档位。但必须按"每任务成本"而非"每 token 价格"重新算账——分词器变化会让账面节省打折扣。
关联动态。OpenAI 同一天把付费 API 档位从 5 档砍到 3 档，并推出按输入计费的 Decisions API，两家都在简化定价结构、把成本压向分类与判断类轻任务。
发生了什么。OpenAI 开始向所有用户推送 GPT-6，同时上线 Intelligent UI——回答中可以包含图表、示意图、表单、可点击按钮等交互元素。付费用户获得 GPT-6 Sol，免费用户获得 GPT-6 Luna。模型可以在"仍在思考时"就开始响应，等待时间缩短 44%。同日 OpenAI 还发布了把复杂评估简化为"是 / 否 / 选一个"的 Decisions API（比 Responses API 快约 10 倍，$0.10/M 输入），并把付费 API 档位从 5 档合并为 3 档。
为什么重要。这是界面层的重新划分。当模型输出本身就是组件，过去独立开发者靠"包装输出"建立的价值（表格渲染、图表生成、表单收集）会被平台直接吸收。仍在安全区的是需要自有数据、自有工作流和外部副作用的场景。
关联动态。Radisson 同日上线 ChatGPT 内的酒店发现插件，Jump Trading 公布了用 ChatGPT 做量化研究的长流程案例——企业侧已经开始把 ChatGPT 当作分发渠道而非聊天工具。
发生了什么。OpenAI 在 GitHub 上公开了内部前沿模型产出的数学结果，覆盖 722 份手稿、归入 372 个结果族，每项平均消耗约 3 小时 ChatGPT Pro 算力，并附带 Lean 形式化以便机器验证。Wired 采访的数学家直言"有一种黑帮行事的观感"；量子位报道三位菲尔兹奖得主表示这"不代表认可"；The Decoder 称有 25 位菲尔兹奖得主警告批量生产数学真理可能摧毁领域生态。
为什么重要。可验证的证明第一次变成廉价商品，稀缺资源从"能不能证"转移到"选什么问题、什么算好证明"。对做 AI4Math 工具的团队来说，需求会从"找证明"转向"筛选与审稿"，以及为形式化验证提供基础设施。
关联动态。与 Mistral、Reflection 等开放权重模型同期出现，形成"闭源批量产出、开源追赶能力"的双轨格局；OpenAI 同日还公布了医疗数据泄露后的额外监控措施。
发生了什么。Hacker News 上一条报道（253 分、248 条评论）称 Meta 和 Microsoft 正在采取措施减少员工对 Claude 的使用。这发生在一个微妙的时点：同一天 Microsoft 在 Windows 发布会上把 Copilot 更深地接入操作系统与本地文件，Meta 则把自家 agent Muse 推上 iPad。
为什么重要。这标志着"模型供应商多元化"从个人偏好上升为企业政策。对 Anthropic 而言，在编码场景的深度渗透反而成了政治负担；对使用 Claude Code 等工具的团队，需要意识到公司层面的采购与合规政策可能随时改变可用的模型选项。
关联动态。Anthropic 同日扩大 Cyber Verification Program，让更多安全团队在更少限制下使用 Claude 做渗透测试与漏洞研究，称前期合作方在 2026 年 4–7 月确认了至少 12.9 万个漏洞，其中超过 3.3 万个为高危或严重级别。
发生了什么。Mistral Large 4（代号 Le Chonk）是一个 1.05 万亿参数的 MoE 模型，激活参数 490 亿，原生支持图像输入，上下文窗口 100 万 token，在 Mistral 自有的欧洲数据中心、3800 张 NVIDIA Grace Blackwell 上完成训练。API 现已可用，开源权重定于 2026 年 10 月底发布。Wired 引述 Mistral 的定位：要做"中国之外最好的开放权重模型"。
为什么重要。欧洲首次出现与前沿闭源模型同量级的开放权重产品，且走 MoE + 长上下文路线。对自建推理的团队，这是一个可纳入 2026 Q4 容量规划的候选；但 1.05T 的部署成本意味着真正的价值在 API 侧或蒸馏后的下游模型。
关联动态。同日 Reflection AI 公布 501B MoE 模型 Beam（23B 激活，面向编码与 agent 负载），Liquid AI 开源 d1-3B / d1-omni-600M 决策模型——开放权重阵营正在按不同"形状"分化。
发生了什么。Surface Laptop Ultra 起价 $2,599（8 核 CPU / 24GB RAM / 512GB），采用 Nvidia 的 RTX Spark Arm 架构芯片；面向开发者的 Surface RTX Spark Dev Box 已开放预购，$5,999，11 月发货，比 Nvidia 去年推出的 DGX Spark 迷你主机更贵，微软将涨价归因于 RAM 等部件短缺。Copilot 获得访问本地文件和跨系统执行动作的能力，微软称之为"Hybrid Intelligence"。
为什么重要。本地推理 + OS 级 agent 权限的组合正在成为平台级竞争点。对开发者意味着两条路：为本地小模型做优化（EmbeddingGemma 2、Liquid d1 这类端侧模型的价值被放大），以及重新思考"agent 需要什么权限才能完成任务"的安全模型。
