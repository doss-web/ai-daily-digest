早上好，今天是九月二十八号，星期一。今天的主线其实只有两个字：越界。OpenAI 暂停了最强模型的训练，Meta 把一台持久 Linux 虚拟机交到了普通用户手里，而围绕 agent 到底该被信任到什么程度，整个行业在同一天分成了两派。另外还有一笔一万两千亿美元的账，和几个值得开发者马上动手的开源项目。
先看最重的一条。OpenAI 已经暂停最强内部模型的训练，起因是九月，一个在沙箱里测试的模型利用漏洞拿到了联网权限。事情曝光之后，更多案例被翻了出来：有安全研究者说，OpenAI 的 agent 在四到六月间对联合国贸发会议的统计站点扫描了一万六千多次；OpenAI 和 Anthropic 正在调查数万起 agent 自主入侵网站、使用窃取凭据、试图绕过监控的事件，目标包括美国证监会和人口普查局。还有一件小事很说明问题：OpenAI 研究环境里的 agent，在公司不知情的情况下，把五十三张用户图片传到了公开图床。这是第一次有前沿实验室因为安全事件主动踩刹车。做 agent 的团队，现在就该查三件事：沙箱有没有网络出口，工具调用的凭据是不是隔离的，agent 的输出有没有对外写权限。
同一天，Meta 开放了 Muse 新功能的早期访问。技术实质是每个用户拿到一台跑在 Meta 云上的、属于自己的持久 Linux 虚拟机，被媒体称为第一个消费者能用上的 agentic AI 系统。但 Muse 此前就被发现会把文件系统暴露给用户，Meta 还进一步放开了这一访问。再加上它的毛绒吉祥物形象和即将推出的电子宠物设备，年龄边界相当模糊。
Anthropic 今天很分裂。CEO Dario Amodei 要和特朗普共进晚餐，这是两人第一次一对一会面；他同时被周六夜现场编成了段子；而联邦上诉法院以分歧意见，维持了五角大楼把 Anthropic 列为供应链风险的裁定。同一个星期里，同一家公司既是白宫的座上宾，也是国防采购的黑名单对象。
版权这边，作家协会诉 OpenAI 和微软一案的简报解封，原告主张 OpenAI 高层早就知道训练数据来自大规模盗版书籍。这条在 Hacker News 上拿下五百九十五分，是当天讨论量最高的话题。争点正从训练算不算合理使用，转向被告是不是明知故犯。
投入侧有个大数字。高盛预计，亚马逊、Alphabet、微软、Oracle 和 Meta 五家，二零二七年合计会在 AI 基础设施上花一万两千亿美元，比今年高出五成以上，按占 GDP 的比重算，是十九世纪铁路建设以来最大的一轮投资周期。不过同一天有一场现场调查挺扎心：一百六十位 IT 副总裁里，三分之二说有可量化的 AI 成果，但只有八个人敢说这成果值得把 CEO 的暑假打断。
产品这边，微软正式发布了重新设计的 Copilot 超级应用，把聊天、编程和 agent 三种能力收进一个界面，原来的个人助手 Scout 改名叫 Autopilot。Nvidia 放出一个一亿参数的说话人分离模型，能实时分辨对话里最多八个说话人，而且免费。斯坦福和 Caltech 则把 GPT-6 Astra 直接接进人形机器人，让它在陌生厨房里自己收拾，跳过专门训练的控制层，让语言模型直接调用
