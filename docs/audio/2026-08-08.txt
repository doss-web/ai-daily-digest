AI 每日简报，周六，2026-08-08。以下是今天的重点。
行业新闻。
发生了什么。本周 Google 宣布了史上最大规模的 AI 组织调整。Demis Hassabis 转任主席兼首席科学家，Koray Kavukcuoglu 接管 Gemini 与产品执行的运营权；Jeff Dean、Sanjay Ghemawat、Oriol Vinyals、Quoc Le 等传奇工程师离开 Google，联合创办 Discovery Loop，专注自动化机器学习与科学发现，已获多家顶级风投支持。业界普遍认为，Google 模型表现落后于 Anthropic 和 OpenAI 是这次洗牌的导火索。
为什么重要。这是 Google 系 AI 人才最大的一次集体出走。Discovery Loop 的方向——用 AI 自动化研究本身——可能成为下一个前沿赛道，值得密切关注其早期产出。
关联动态。几乎同期，Meta 发布了 Muse Spark 1.2 与 Muse Code，模型竞争格局正在快速重组。
发生了什么。DeepMind 发布 WeatherNext 模型，能用较低分辨率的气象数据准确预测风暴路径和强度，比现有方法更早给出预报。研究人员承认尚未完全理解其内部工作机制，但模型将开源。
为什么重要。气象预测是 AI for Science 中少数能直接影响数十亿人和基础设施的领域。开源意味着研究者可以在自有数据上复现与扩展，而不是被锁在厂商 API 里。
发生了什么。8 月 6 日，阿里开启视频生成大模型 Wan 3.0 公测。除文生视频、图生视频外，还支持把文档、PPT 直接转化为视频，直接切入企业内容生产场景。同日阿里还发布了国内首个 AI 语音平台 CosyVoice Studio，将语义理解融入语音能力。
为什么重要。多模态生成从"媒体素材"走向"办公资料"是一个明确的差异化方向。对做视频工具链的团队来说，Wan 3.0 的 API 能力和文档转视频的效果值得第一时间实测。
发生了什么。蚂蚁集团正式开源 Avernet，定位为多智能体协作基础设施，社区版已上线。据介绍已在内部跑通 12 大业务场景，任务完成率超 90%。InfoQ 报道称其解决的核心问题是多智能体"找不到、对不齐"的协作难题。
为什么重要。多 agent 系统最大的工程瓶颈是 agent 之间如何发现彼此、对齐目标、共享上下文。这是国内大厂第一次把这类基础设施以社区版开源，值得直接上手评估。
关联动态。腾讯云同日开源 TencentDB Agent Memory v2.0，两家不约而同押注"多 agent 协作的底层设施"。
发生了什么。Databricks 在官方博客分享了管理 AI 编码成本的具体实践，声称将 AI 编码支出降低了 70%。此事在 HN 上引发 139 分、129 条评论的热议。同一天，404 Media 报道了"Tokenpocalypse"现象——企业正在疯狂控制 AI token 支出，Accenture 内部音频泄露称 token 消耗主要来自非工程师群体。
为什么重要。在模型能力竞赛放缓之后，成本治理已成为企业采用 AI 的第一议题。"降本 70%"的具体做法（缓存、路由、模型分层）是每个 AI builder 都可以直接借鉴的作业。
发生了什么。Oracle 宣布禁止 AI 生成代码提交到 OpenJDK，尽管其董事长 Larry Ellison 曾声称"Oracle 不写自己的代码"。消息在 HN 上获得 331 分、230 条评论，社区讨论激烈。
为什么重要。这是主流开源项目首次以"全面禁令"而非"审核机制"回应 AI 代码贡献。对依赖开源生态的企业而言，这预示着 AI 贡献代码的治理规则正在分化——有的项目拥抱，有的项目封锁。
发生了什么。据 Reuters 报道，阿里计划对其下一代开源 AI 模型的大型商业用户收费。这是中国开源模型厂商在"开源 vs 商业可持续"之间的又一次探索。
为什么重要。开源模型的免费午餐可能正在结束。如果企业重度依赖国产开源模型，需要开始评估许可证变化与供应商锁定风险。
发生了什么。OpenAI 宣布从下周起，ChatGPT 免费版和 Go 版用户可获得无限文本聊天，使用较小的 GPT-5.6 Luna 模型，并新增"思考按钮"支持更长时间推理。同时 GPT-5.6 Sol 在 ChatGPT 中得到更新，加入推理强度滑块，响应更聚焦。
为什么重要。无限免费聊天是 ChatGPT 获客策略的重大转变，也意味着 OpenAI 的推理成本结构已经允许把最弱模型当作免费漏斗。对竞品和依赖 API 收费的创业者都是压力信号。
