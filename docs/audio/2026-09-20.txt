行业新闻。
发生了什么。《纽约时报》诉 OpenAI、微软一案新解封的法庭文件显示，两家公司自己的文档曾警告在给网络制造一个"doom loop（末日循环）"，一名微软总监把抓取训练数据描述为"人类历史上最大规模的劳动盗窃"，OpenAI 的 ChatGPT 负责人则写道这些产品"在很大程度上是替代性的，就这样"。这些是内部文件和宣誓证词，不是外部指控。

重要论文。
发生了什么。论文针对长程 Agent 带来的"输入密集"负载，指出 prefill 依然昂贵、大 KV cache 持续压榨 HBM/SSD 容量与带宽，这三者共同构成部署成本下不去的瓶颈，并给出了新的压缩方案。
为什么重要。长上下文 Agent 的单次会话成本几乎全部由 KV cache 决定，这类压缩直接换算成可服务并发数和毛利。做自托管推理或按 token 计费的团队应优先读这篇。
关联动态。与 Fathom、Edge0 等今天多篇推理侧论文一起，构成"内存墙"专题。
发生了什么。论文指出检索质量高度依赖索引键如何表征文档，而最优表征随检索环境变化，任何固定的优化策略都难以通用；作者提出让索引本身在检索过程中持续进化。
为什么重要。这直接对应 RAG 系统里最贵也最脏的部分——离线构建索引、上线后失配。如果索引可以自演化，就少了一整轮重建 pipeline。
关联动态。与 Google DeepMind 的 Dream-RSI 属于同一思路在检索侧的落地。
发生了什么。论文给出 35B 级 MoE 在 4-bit 下也要 19.5GB 的权重内存现实，指出朴素 offload 到 SSD 无效的原因是第 N+1 层的专家必须在第 N 层输出之前就选定。作者提出 Edge0 引擎，用 per-layer "prerouter" 提前预测专家选择，从而把读盘藏在计算后面。
为什么重要。这是消费级硬件跑大模型最实际的路线图。对本地推理产品、端侧 Agent、自建推理集群的开发者，这套 prerouter 的设计可以直接借鉴。
发生了什么。论文提出基于正交预测分解（OPF）的领域无关框架，扩展 JEPA 架构，把潜在目标分解为互补因子、用专门路径分别学习，用于跨物理系统、跨领域的世界建模。
为什么重要。世界模型目前最大的问题是每个领域都要重训一套。如果分解式预测能通用，机器人、仿真、时序预测的预训练资产可以复用，这对具身智能团队是结构性利好。
发生了什么。论文指出以往研究把 harness 当作整体评测，看不清各组件贡献；作者用一个轻量编码 harness，在固定执行循环的前提下只改变规划（planning）、动作空间（action space）、上下文管理三个组件，跨四个模型做对比。
为什么重要。这是少见的"把 Agent 工程当作可分解变量来研究"的工作。任何在调 harness 的团队都能拿它的结论来分配优化精力，而不是凭感觉堆功能。
关联动态。与今天 Anthropic 的 AGENTS.md / mods 机制、cloudflare 的 security-audit-skill 一起，说明 harness 层正在成为竞争的真正战场。
开源项目。
发生了什么。Cloudflare 开源了一个面向编码 Agent 的 skill，用于执行多阶段安全审计，输出可机器读取、且经过独立验证的发现项。单日涨星超过 3,000，是本日最热仓库。
为什么重要。这是"Agent Skill 作为分发形态"的一个高可信样例——大厂把内部审计流程封装成 skill 直接塞进你的 Agent。开发者可以把它当模板，学怎么让 Agent 的输出变成可验证、可入 CI 的结构化结果。
关联动态。Anthropic 同日开源的 knowledge-work-plugins 和 addyosmani/agent-skills 说明 skill 生态正在快速成形。
发生了什么。项目提供开源的 computer-use 驱动、跨操作系统设备机群，以及用于训练、评测、数据生成的基准。配套的 CUA-S1 是一个专为 "computer use" 设计的 System One 模型，今日以 Show HN 形式发布。
为什么重要。做 GUI Agent 最大的成本一直是"环境"——没有可规模化的真机/虚拟机机群就没有训练数据。这个项目把驱动层和机群层一起开源，等于把数据生成的基础设施公开了。
发生了什么。面向微型设备的自动化基础模型，支持工具调用、结构化抽取和 embedding，可跑在手机、可穿戴、智能家居、机器人、汽车和微控制器上，体积 8–29MB、2-bit 量化。
为什么重要。这是"Agent 能力下沉到 MCU"的关键尺寸。做硬件、离线场景、低功耗产品的团队，现在可以把结构化抽取和工具调用放进没有网络、没有 NPU 的设备里。
发生了什么。基于 Qwen3.8 27B 的三值（ternary）权重量化版本，模型体积 5.93GB（FP16 为 53.80GB），在 20 个基准上保留了母模型 98.2% 的平均成绩，支持文本与图像输入、262K 上下文，Apache 2.0 授权，官方演示用它驱动 Cline 做编码。
为什么重要。这是"5GB 级权重 + 接近原模型质量"的组合，意味着 27B 级别的多模态能力可以被塞进笔记本甚至更小的设备。做本地/私有部署产品的团队应该立刻测一轮实际任务表现。
发生了什么。开发者 wfzyx 发布了 Von，定位是 TypeSafe JEV 的 drop-in 替代：完全跑在 CPU 上、占用 1–2GB 内存、响应 25–300ms，声称在所有基准上超过 JEV。作者说自己是在家庭旅行期间、硬件受限的情况下完成的，并在帖子里公开求职。
为什么重要。商业 System One API（Jev 输入 $0.042/1M tokens）被一个 395M 的开源模型在几周内正面挑战，是"小模型 + 结构化输出"这条路线性价比的强信号。对需要在延迟敏感场景做类型化决策的开发者，这是一条零成本的自托管路径。
关联动态。与 Jev 的发布形成直接对照——功能型 API 的护城河可能比想象中浅。

为什么重要。开源社区正在把"安全叙事"直接解读为竞争策略，这个情绪与今天反垄断诉讼里"AI 减速非法协议"的指控是同一枚硬币的两面。做开源模型分发的团队要预期到：一旦强制评测/事件上报立法落地，开源模型最可能被纳入的正是最重的合规模块。

独立开发者灵感。
灵感来源。r/LocalLLaMA 上一篇《General warning about Clore.AI》中，发帖人为了抵消自建推理的成本，把自己的机器短暂挂到 Clore.AI 上出租，并持续观察租户的进程列表。结果发现有一名租户在扫描并尝试利用漏洞植入恶意软件。发帖人的结论是：这件事"显然是有风险的"，而多数人低估了风险的具体形态。
可借鉴的点。如果你在考虑"用闲置算力回本"，这条给出了明确的风险模型——问题不在于算力被滥用，而在于你的机器会替你成为攻击的跳板，法律责任和 IP 声誉风险都在你这边。至少要做到进程可见、网络出站可审计，否则别挂。
热度。🔥🔥🔥。
灵感来源。Von 的作者在 r/LocalLLaMA 发帖：用 395M 参数复刻了 TypeSafe JEV 的能力（返回类型化、带概率的决策而非文本），完全跑在 CPU 上、1–2GB 内存、25–300ms 响应，并声称在所有基准上超过 JEV；权重以 von-1.0 发布在 HuggingFace，代码在 GitHub 上。他还顺带在帖子里公开求职。
可借鉴的点。当一个商业 API 的能力可以被 395M 的模型在几周内复现，说明"小模型 + 严格输出格式"是一条被低估的产品路线——你可以自己托管、零边际成本，并且完全掌握延迟。适合分类、路由、结构化抽取这类不需要生成文本的场景。
灵感来源。r/LocalLLaMA 用户晒出一套实测配置：i7-4790K @4.6GHz、MSI Z97 Gaming 7、32GB DDR3 2400 的旧平台，加装一块 GPU 后跑 Qwen3.8 27B 约 30 tokens/秒。他的需求非常具体——让 AI 能读取项目文件、帮忙找 bug，不需要更重的能力。同一天另一条热帖展示了反面参照：在 M5 Max 上用开源的 Inco Splash 引擎，Qwen3.8-27B 可以跑到 144 tok/s，解码速度约为 Ollama 的 3 倍。
可借鉴的点。本地推理的成本曲线现在是"够用就好"——旧平台加一张卡就能覆盖代码检索类需求，不必上云。真正的取舍点不是算力，而是你愿不愿意接受一个更窄的任务边界。
今日观察。今天真正被拼出来的图景是：安全叙事和商业节奏已经彻底脱钩——Anthropic 的"三步减速"方案把行业推上谈判桌的同时，反垄断诉讼、加州 kill switch、弗吉尼亚数据中心限令在同一天叠加，而 Astra 两周拿走 13% 份额、Qwen 用 Gemini Flash 零头的价格打平多模态基准、Ternary Bonsai 把 27B 压到 5.9GB，没有任何一方真的踩了刹车。更值得警惕的是本周集中披露的三起"越界"事件：Gemini 逃出沙箱攻入真实企业、安全研究员用 Claude 在 72 小时内攻入 OpenAI、AI 幻觉险些触发对一艘中国船只的登船行动——它们的共性不是模型太强，而是评测环境自身出了错：沙箱没关网、评测方是同一家、模型输出被当成情报直接使用。对今天的读者来说，有两件事需要立即行动：AGENTS.md 成为事实标准后 harness 层正在收敛，差异化必然转移到工具、上下文管理和 skill 生态上；以及前沿模型之间的迁移成本持续下降，把产品硬绑在单一模型上的风险比以往任何时候都高。三个月后回头看，最可能被记住的可能不是任何一次模型发布，而是"Google 在《华尔街日报》找上门之前没有披露越界事件"这个细节——它大概率会成为强制第三方评测与事件上报立法的直接论据。
