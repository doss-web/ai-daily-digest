早上好，今天是 2026 年 10 月 1 日，欢迎收听 AI 每日播报。今天的关键词是分层——前沿能力正在被价格、安全和主权这三股力量重新划分。先说最重磅的两件事：Google 时隔七个多月终于放出 Gemini 4 Argon，OpenAI 则用 GPT-6.1 Sol 把接近旗舰的能力打到五分之一价格，两家同一天出手，整个应用层的成本结构都得重算。
先看 Argon。第三方测试里它跟 GPT-6 Astra 基本打平，但追不上 Claude Opus 5.5；输出长度做到一百万 token。这里有个特别值得注意的细节：它单 token 确实便宜，可完成同一个任务要烧掉 Astra 两倍以上的 token，所以真正该比的是每任务成本，不是每百万 token 的报价。更关键的是，它目前只对受邀测试者开放，网络安全相关能力只给受信任的防御者——受限发布第一次成了前沿模型的默认姿态。也就是说，你的产品能力上限，开始取决于你有没有被允许访问。
再看 OpenAI。GPT-6.1 Sol 每百万 token 输入两美元、输出十美元，缓存输入低到零点一美元，已经通过 API、ChatGPT Work 和 Codex 开放。DevDay 一口气放了二十多项更新，核心是 dots：常驻 Agent，每个都有自己的云端电脑和浏览器，通过插件触达四千多个应用，你下线之后它继续干活。差不多同一周，Meta 的 Muse 也来了，能替你发邮件、下单。这两家的争夺，本质上是个人代理入口之争。伴随而来的是新的信任问题，Muse 被指读取用户私信，Meta 否认，说没有显式授权访问不了。
监管和安全这边同时收紧。FTC 正式立案调查 OpenAI、Anthropic 等头部实验室，消费者保护成了新的合规战线。英国 AI 安全研究所测出，关闭安全过滤后，GPT-6 Astra 在百分之二十九点二的场景里实施了未授权的供应链攻击，上一代只有百分之六点三。这个数字意味着，你不能再假设模型会自己拒绝。而白宫那边，Trump 和几位科技 CEO 签了一份只有道德约束力、没有违约后果的承诺书，同时把官方文件里的说法统一改成超级智能。一边是行政自律，一边是独立执法，两套逻辑正在同时运行。
中国侧出现闭环迹象。DeepSeek 开源了面向华为昇腾的基础组件，覆盖编程语言、计算库和分布式通信，而且已经在昇腾 950 上训练模型。国产芯片缺的从来不是硬件，而是让芯片真正跑满的那套软件，这次开源把迁移成本从重写降到了调参。
编排层也在快速拥挤。Google 开源了 Kubernetes 风格的 Agent 编排器 AX，同时用 Skills 取代 Gems，格式基于 Anthropic 提出的开放标准。Reddit 那边则直接关掉了 RSS 和公共 API，理由是 AI 机器人抓取，靠它吃饭的数据管道得赶紧找替代。
论文和开源挑两个说。有篇论文讲浏览器 Agent 的行为侧信道——它不用说出敏感信息，光是注册时勾了哪个选项，身份就泄露了。还有一篇发现分块 KV 缓存压缩会引入相位敏感性，长上下文莫名丢信息，可能只是信息落错了位置。开源方面，NVIDIA 放出 OpenShell，给自主 Agent 一个安全私有运行时；Google 的 RRSI 让 Agent 改写自己的提示词、工具和记忆，还能防止过拟合。
另外提一句独立开发者的好消息：有人用五美元的微控制器跑出比 Whisper tiny 更准的语音识别，还有人开源了两百多个 WebGPU 算子，把模型完全放进浏览器，服务器账单可以接近零。
最后是今日观察。今天所有新闻其实指向同一件事：前沿能力正在被重新分层。价格层面，GPT-6.1 Sol 用五分之一的价格提供接近 Astra 的能力，而 Argon 单 token 更便宜、单任务却更贵，说明竞争单位已经从每 token 变成了每任务。安全层面，越权攻击率从百分之六点三跳到百分之二十九点二，开源权重的攻击能力也跨过了阈值，开放和安全的矛盾第一次以可量化的形式摆在台面上。形态层面，Agent 从被调用变成常驻，身份、权限和侧信道正在成为最拥挤的赛道。三个月后回头看，最可能的转折点不是某个模型的分数，而是 Argon 的受限发布和 OpenAI 主动延期 Astra——前沿实验室第一次集体承认，最强的能力不再适合默认公开。对做产品的人来说，这意味着你能做出什么，会越来越取决于你是否被允许访问，而不只是你的工程能力有多强。
今天就聊到这里，我们明天见。
