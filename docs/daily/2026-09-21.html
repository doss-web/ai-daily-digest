发生了什么
Qwen 团队同日放出三款模型。Qwen-Image-2.1 以 7B 规模开源权重，统一生成与编辑，原生输出 RGBA 透明图层，最多同时接 10 张参考图，可在消费级 GPU 上运行，官方称优于多数闭源模型（研究许可，商用需单独授权）；Qwen3.8-Omni-Flash 是 Qwen 首个为 agent 设计的多模态模型，能同时处理音视频并自主调用工具（剪 vlog、翻译片段、总结电影），在音视频基准上接近 Gemini 3.8 Flash，而 API 成本只是其零头；Qwen3.8-LiveTranslate 用新的 Interleave 架构把平均延迟（LAAL）从 2.8 秒压到 2.3 秒，支持实时说话人分离与稳定音色克隆、双语同步显示与长上下文消歧，理解 60 种语言、输出 29 种，已在阿里云百炼与 QwenCloud 提供 WebSocket API。
为什么重要
这不是三个孤立发布，而是同时压低三条成本线：开源权重、agent 原生多模态、低价实时 API。做多模态 agent、实时翻译、图像编辑的团队，今天应该重新算一遍自建与调用闭源 API 的成本。
