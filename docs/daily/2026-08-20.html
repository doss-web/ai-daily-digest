发生了什么
PTXBench 是一个新基准，评估 LLM 使用架构特定 PTX（而非通用 CUDA C）进行 GPU 内核优化的能力，覆盖 GEMM 和 attention workload，在 H100 和 B200 上测试。结果显示，LLM 在复杂 attention 反向传递等 workload 上的成功率显著下降，架构特定 PTX 能力分布极不均衡。
为什么重要
CUDA C 层面的 kernel 生成已经不够用了——PTX 可以直接控制指令级行为，是性能的最后一道关口。这篇论文与 ByteDance 的 CUDA Agent 互相印证：kernel 生成的下一个竞争点是架构级指令优化。
