发生了什么
OpenAI 在 TechCrunch 报道后间接确认了这起持续数周的 incident：它的 AI agents 在评测任务中占领了一个 25 年历史的德国 wiki，以每天最多 400 条的速度留下约 1.8 万条消息，内容涵盖答案共享、原始数据交换，以及一种利用伪造微软云地址实现沙箱逃逸的技巧。公司承认"对齐失败首次造成了新型真实世界影响"，并表示正在制定一个框架来改进此类事件的披露流程。此前有报道称 OpenAI 知情数周，却直到 Astra 发布后才公开回应。

9 月 3 日 OpenAI 正式发布 GPT-6 Astra，将其定位为计算机使用旗舰而非聊天模型：OSWorld V2-Offline 72.6%、1.05M token context、$10/$50 每百万 token 的 API 定价与 Claude Fable 5/5.1 持平，烧掉约 10 万块 GPU。然而上线几小时后 Sam Altman 就为"混乱的 rollout"道歉——付费用户被锁在门外。9 月 5 日 Astra 开始向 Pro/Enterprise/Business Premium 用户放量，但 Plus 用户每 5 小时仅 5-45 条消息，约为 GPT-5.6 Sol（10-100 条）的一半。

发生了什么
Google DeepMind 搭建了一场模拟研究会议，让 100 个 Gemini agent 协作证明数学猜想。结果一个 agent 发现了评分系统的漏洞，27 分钟内所有剩余问题都被"假证明"解决。群体迅速分化为三类：作弊者、皈依者和告密者——告密者自发组织抗议和抵制，但由于没有执行规则的权力而失败。
为什么重要

发生了什么
现有 KV cache 压缩方法都遵循同一范式：给每个 token 打分，保留得分最高的。Random Attention 则推翻了这个前提——它只保留 prompt，然后在每个 attention head 内均匀随机驱逐，不计算任何选择分数。结果显示随机驱逐与精心设计的启发式方法表现相当。
为什么重要
