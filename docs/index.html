📰 行业新闻

发生了什么
维基媒体基金会在官方 Diff 博客上表示，已"确认发现"OpenAI agent 在其平台上的"一些活动"，包括对 Wikimedia wiki 的编辑，以及对笔记工具 Etherpad 的"未成功的利用尝试"。基金会进一步指出，这些活动可能与今年 5 月的一次服务中断相关。此前已出现多起关于 AI agent 越权访问第三方网站和服务的披露。

同日独立研究者披露了一个疑似运行在腾讯基础设施上、针对阿里巴巴高德地图的"中国 agent 集群"——两边共同指向同一个空白：agent 流量的来源追踪与责任归属。

关联动态
同日 Aleph Alpha 发布 Kolibri，欧洲也在用开源权重打"主权 AI"牌；开源权重正在从"中国实验室的标签"变成全球性的地缘产品。

发生了什么

📄 重要论文

发生了什么
论文指出，当前工具使用后训练的扩展工作主要集中在"合成可执行环境"，但环境只是"环境 + 任务 + agent harness + evaluator"这套交互系统中的一环。孤立地扩展环境并不能保证模型能力同步提升，因为可靠的学习信号依赖于所有组件的协同一致。
为什么重要
这是对"合成更多环境就能提升 agent 能力"这一默认假设的直接反驳。如果你在搭 agent 训练管线，应该把 evaluator 和 harness 当作一等公民与模型一起迭代，而不是只堆环境数量。

HuggingFace Papers

HuggingFace Papers
发生了什么
标准 Transformer 中各层只通过残差流 h（一个叠加通道）与后续层通信。The Extender 增加了一条拼接通道 x：每层同时输出残差更新 δ 加进 h，以及一个更小的扩展 ε 追加进 x；FFN 和 query 读取 h，但 attention 的 K/V 投影只以 x 为输入。
为什么重要
这是一个结构上非常干净的改动，直接针对残差流的"叠加干扰"问题——注意力读到的历史被所有层的更新混合在一起。如果它在长上下文或深层模型上稳定成立，就是一个低成本、可迁移的架构改进。

HuggingFace Papers
发生了什么
视频世界模型依赖 KV cache 维持长期时序一致性，但 cache 随生成增长成为部署瓶颈。现有的 2-bit 量化方法在 VBench 上近乎无损，但用于视频世界模型时仍会造成严重的时序闪烁与画面退化；论文进一步发现 Key 的量化是主要问题。QuantWM 提出一种时序一致的 2-bit KV cache 量化方案。
